# 공개 점검 기록

2026-09-11 기준 스킬 문서 0.9.2, 파서 0.8.1을 점검했다. 이 문서는 검증 범위 기록이며
운영 절차는 [SKILL.md](../SKILL.md)를 따른다. 2026-09-12 운영자 확인을 거쳐
`publishing.yml`의 `published`로 전환했다.

## 문서와 AI 실행 안내

- 기본 실행을 설치 → 전체 이미지 판독 → 상세 판독/입력 보완 → 검증 → 파싱 → 엑셀 → 사용자 대조 순서로 정리했다.
- 모든 페이지의 문서 종류·취소선 판독, 한 곳이라도 취소선이 있는 PDF의 전체 상세 판독, 기대값의 독립 확인을 명시했다.
- 필수 이미지 판독과 선택적 후보 판단을 구분했다. 자동 기대값 검사 범위와 권리자·채무자·접수정보의 별도 원본 대조를 설명했다.
- 공개본의 requirements.txt 설치, OS별 venv 실행, 페이지별 OCR HTML 구조, 실패·부분 결과, 이전 증거와 경로 이동에 따른 재실행 조건을 문서화했다.
- 상세 분석 규칙과 선택적 판정은 해당 상황에서만 참고 문서를 읽도록 분리했다.

## 의존성

직접 런타임 의존성은 pdfplumber와 openpyxl 두 개다. PDF 텍스트·표 추출과 렌더링, 엑셀 생성을
각각 담당하므로 제거하지 않았다. 다른 스킬이나 OCR·비전 SDK를 설치할 필요가 없다.
PDFium과 Pillow 등은 pdfplumber의 간접 의존성으로 설치된다. Poppler는 선택 사항이다.

Python 3.12 / Windows 환경의 기존 검증 버전은 pdfplumber 0.11.9, openpyxl 3.1.5다.
별도 빈 venv에서 공개본 requirements.txt만 설치한 검증은 pdfplumber 0.11.10, openpyxl 3.1.5와
간접 의존성 8개로 수행했다. 이 환경에서 공개 코드 사본에 합성 테스트를 붙여 256개 전체 및
CLI 도움말 6종을 통과했다. Poppler가 없는 PDFium 렌더링 경로도 테스트에 포함한다.
선언된 최소 버전과 모든 OS·패키지 조합을 검증한 것은 아니다. 의미 없이 의존성 상한을 추가하거나
렌더링·PDF 해석 라이브러리를 중복 도입하지 않았다.

## 검증 범위와 남은 제한

- 자동 테스트 256개: 단위 88, 릴리스 53, 이미지 기록 38, 이미지→분석→엑셀 연결 45, 일반화 22, 복합 입력 10.
- 합성 이미지 테스트의 판독 기록은 정해진 입력이다. AI의 실제 취소선 인식률을 측정한 결과가 아니다.
- 실제 사용자 자료에서는 8개 분류 폴더의 14개 PDF·65쪽을 원본 대조하고 조서까지 검증했다. 전체 212개 PDF·1,421쪽 중 나머지 198개 PDF·1,356쪽은 이미지 전수 검증이 남아 있다.
- 사용자는 현재 범위에서 작업을 마무리했다. 이를 남은 입력이나 모든 신규 서식에 대한 사용자 승인으로 확대하지 않는다.
- 일부 공동담보 서술에 페이지 하단 안내 문구가 남는 표시상 문제가 있다. 복잡한 공유지분·복수 채무자, 세트 밖 담보, 흐리거나 누락된 페이지는 별도 대조·보완 대상이다.
- 표본 검증과 패키지 검증은 법률상 효력, 금융조회서 대사, 회계처리 판단을 대신하지 않는다.

공개본에는 코드·일반 문서·설치 요구사항만 포함한다. 실제 PDF·OCR·이미지·조서·판독 기록·
회사별 정답은 포함하지 않는다. 공개 전 배포본의 파일 게이트, 금지 문자열, 문서 링크,
독립 설치와 실행을 다시 확인했고 운영자가 남은 한계를 검토했다.

이번 공개 사본은 스킬 파일 21개와 미러 루트 라이선스·자동 README·카탈로그로 구성했고,
파일 게이트·금지 문자열·로컬 문서 링크 검사를 통과했다. 테스트·lock·실데이터는 배포 대상에서
제외했다. 실행 계약이 오래된 합성 JSON·README 샘플 3개도 공개 대상에서 제거했다.
현재 공개본에는 PDF·OCR·이미지·조서뿐 아니라 샘플 데이터 파일도 없다.
저장소의 `published` 목록에 등록되어 공개 미러 동기화 대상이다.

사이트 frontmatter의 name·title·description 및 이름 규칙을 확인했다. 범용 스킬 검증기는
title·category·tags·version 확장을 허용하지 않아 원본 검사에서는 해당 네 필드를 보고한다.
사이트 계약에 따라 필드를 유지하고, 임시 사본에서 확장 필드만 제외해 이름·설명·본문 규칙을
별도로 통과시켰다. 이를 범용 검증기의 원본 전체 통과로 보고하지 않는다.
