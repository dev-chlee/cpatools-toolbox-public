# registry-mortgage-analysis


부동산등기부등본 PDF를 일괄 파싱해 **근저당·소유권·(가)압류**를 추출하고, **공동담보 중복을 제거한
순 담보금액**을 산출해 **감사 워크페이퍼(엑셀)** 를 만드는 AI 스킬이다. 이미지 입력 가능한 에이전트 또는 사람의 원본 판독이 필요하다.

## 무엇을 하나
- 모든 PDF·모든 쪽 이미지 판독 → 취소 범위 제외 → 표제부·갑구(소유권)·을구(근저당)·하단 요약을 구조화 파싱
- 현행(말소 제외) 근저당의 채권최고액·근저당권자·채무자·공동담보목록 추출
- **공동담보목록 번호로 그룹핑해 중복 제거** → 실질 순 담보금액 산출
- 5개 시트(근저당 상세 / 부동산 종합 / 요약 / 담보금액 분석 / 물상보증 매트릭스) 엑셀 워크페이퍼 생성 — 이미지검토근거 시트 추가, LLM 판단 경로 사용 시 판단근거도 추가
- **파일 단위 독립 준비·파싱**과 전체 입력 완료 검증. 누락·미판독이 있으면 최종 조서 생성 차단

> **원본 PDF와 이미지 판독 기록이 필수이며 기존 OCR HTML도 사용할 수 있다.** 입력 준비·보정·실패 처리 기준은 [SKILL.md](./SKILL.md)를 따른다.

## 설치 (AI가 대신 실행)
개발 지식이 없어도 사용하는 AI 에이전트에 "이 스킬 설치해줘"라고 요청할 수 있다. 설치 위치와 실행 환경은 [SKILL.md](./SKILL.md#설치와-최소-의존성)를 따른다(Python ≥ 3.10).

```bash
cd <skill-dir>
python scripts/setup_venv.py     # 스킬-로컬 .venv + 의존성(pdfplumber·openpyxl)
```
> `setup_venv.py` 로 `.venv` 를 만들면 이후 실행은 그 venv 파이썬으로 한다
> (Windows `.venv/Scripts/python.exe …`, macOS/Linux `.venv/bin/python …`). 공개본은 `requirements.txt`로 설치되며 별도 OCR·비전 SDK를 요구하지 않는다.

## 사용법
### AI 에이전트에게
> 등기부등본 PDF 폴더를 주고 "근저당·담보 분석해서 워크페이퍼 만들어줘"

SKILL.md 절차에 따라 이미지 입력 가능한 에이전트가 원본을 판독하고, 검증된 현행 정보가 파싱·순 담보금액·엑셀에 반영된다.

### CLI

실행 명령과 판독 대장 작성 방법은 [SKILL.md](./SKILL.md#전체-pdf-이미지-판독--분석--결과-반영-필수)를 따른다.
기존 두 명령만 실행하는 호출은 이미지 판독 증거가 없어 차단된다.
