## 0.6.0 (2026-09-11)

- 전체 PDF·전체 페이지 사전 이미지 판독을 필수화했다. 한 곳이라도 취소선 존재/불확실이면 해당 PDF 전체의 상세 판독을 검증한다.
- 행 전체 취소, 부분 금액·주소 취소, 말소된 계속 행 및 후속 변경을 반영한 현행본을 실제 파서 입력으로 연결했다. 삭제 이력은 별도 보관한다.
- 이미지 판독에서 확인한 소유자·소재지·근저당 순위/금액·기타부담과 파싱 결과 불일치를 차단한다. 을구 제목 인식 실패를 근저당 0건으로 처리하지 않는다.
- 원본·이미지·판독·현행본·결과 JSON의 해시 증거를 파서 → LLM 판정 적용 → 엑셀까지 이어 검증하고 이미지검토근거 시트를 추가했다.
- **호출 계약 변경**: 파서는 `--image-review`가 필요하다. 미판독/증거 변경은 종료코드 5이며, 검토 전·일부 성공·직접 수정 JSON으로 최종 조서를 생성할 수 없다. `--include-ocr-html`만으로 원본 이미지 검토를 우회할 수 없다.
- 파서 버전 0.5.0. 이미지 판단은 실행 에이전트/사람이 담당하며 별도 클라우드 비전 API를 호출하지 않는다.
- 검증: 기존 88+53건, 이미지 범위 38건, 실제 CLI 연결 회귀 28건 통과. 실 PDF 3개·8쪽과 네이티브 취소선 유무 비교 PDF 2개에서 엑셀 반영 확인. 합성 자동 테스트는 이미지 인식 정확도 지표가 아니다.

## 0.5.0 (2026-08-18)

### Added — 물상보증 매트릭스 (Sheet5)
- `scripts/guarantee_matrix.py` 신규 — Net 을 **소유(담보제공자) x 채무자** 로 분해하는 단일 SSOT 모듈.
  4분면(자기담보 / 물상보증 제공 / 물상보증 수령 / 회사 무관) + 혼합·미상 축.
- Sheet5 `물상보증매트릭스` 신설: Section A 매트릭스, Section B 구분별 해석·감사 조치,
  Section C 그룹별 판정 내역(회사물건/제3자물건 구성 포함).
- Sheet3 요약에 물상보증 분해 5줄 + stdout 에 전 분면 출력(합계 = Net).
- **혼합 축 승격**: 한 공동담보가 회사 물건과 제3자 물건에 걸친 경우를 '구분 불가'로 묻지 않고
  채무자축 기준으로 `혼합 — 회사채무` / `혼합 — 제3자채무` 로 표시. 실데이터 세트1 에서 이 축에
  Net 의 29%(144억)가 모였다 — 묻었다면 매트릭스의 존재 이유가 사라졌을 금액.

### Changed
- **회사귀속 판정 일원화**: `generate_workpaper.classify_ownership` 이 `guarantee_matrix.owner_is_company`
  를 호출한다. 판정이 두 벌로 갈라지면 Sheet1 '회사소유' 표시와 매트릭스 소유축이 어긋난다
  (grouping.py 의 dedup 단일화와 같은 이유).
- **LLM 판단근거 시트 Sheet5 → Sheet6** (매트릭스가 5번을 차지). 코드·SKILL.md 참조 전건 갱신.
- '물건수' 정의 정정: 고유번호(부동산) 기준. 을구 항목 수는 '근저당건수' 로 분리
  (세트3 에서 '물건 56' 으로 표시되던 값의 실제 부동산은 28건이었다).

### Invariants (신규 — 테스트로 강제)
- **셀 합계 ≡ Net**: 모든 그룹이 정확히 한 셀에 배정. 불일치 시 워크페이퍼 생성 중단(exit 1) +
  시트에 검증 라인 인쇄.
- **금액 안분 없음**: 그룹이 분면에 걸쳐도 쪼개지 않는다. 근거 없는 배분 숫자를 조서에 남기지 않는다.
- **채무자 미파싱 = '미상'**: 빈 채무자를 '제3자' 로 떨어뜨려 우발부채를 날조하지 않는다.

### Tests
- 단위테스트 58 → 88 (매트릭스 30건 추가: 축 판정·4분면·혼합 승격·안분 금지·Net 보존·빈 입력).

### 실데이터 검증 (3세트 71 PDF, Net 전건 보존)
- 세트1 490.27억 = 자기담보 235.4 + 혼합(회사채무) 144.0 + 회사무관 110.9
- 세트2 45.00억 = 전액 자기담보
- 세트3 128.59억 = **물상보증 제공 92.82억** + 자기담보 35.77
  → 세트3 회사 소유 부동산이 특수관계 회사 채무(은행)의 담보. v0.4.2 조서에서는 단일 Net 에
  묻혀 있던 우발부채·특수관계자 담보 주석 대상.
