# land-price-query


부동산공시가격 알리미(realtyprice.kr)에서 **개별공시지가**를 조회해 **감사 워크페이퍼(엑셀)** 를 생성합니다.
기본 설치는 openpyxl만 사용하며, **실제 웹페이지 스크린샷**(감사 증빙)은 필요할 때 추가합니다.
AI 에이전트가 설치와 실행을 맡도록 사용할 수 있습니다. **로컬 실행 전용(Windows 기본)**이며, 에이전트의 파일·명령 실행·네트워크 권한을 먼저 확인해야 합니다.

## AI 에이전트: 이 링크를 전달받았다면

이 README는 진입 안내입니다. 실행 순서·입력 계약·출력 경로·오류 처리는 [SKILL.md](./SKILL.md)를 기준으로 따릅니다. 문서를 읽기만 한 상태를 설치 완료로 보고하지 마세요.

1. **실행 가능 여부를 확인합니다.** 사용자 자료에 접근하고 로컬 명령을 실행할 수 있는지, 인터넷을 사용할 수 있는지 확인합니다. 브라우저는 화면 캡처가 필요한 경우에만 준비합니다. 문서만 읽을 수 있는 대화 환경에서는 설치를 완료했다고 말하지 말고, 필요한 실행 환경과 사용자 행동을 하나씩 설명합니다. 에이전트 제품 이름만으로 호환성을 보장하지 않습니다.
2. **공개 도구를 준비합니다.** 공개 저장소의 `work/skill-land-price-query` 폴더와 연결된 파일들을 사용자와 정한 작업 위치에 받습니다. README 파일만 저장해서는 실행할 수 없습니다. 기존 설치가 있다면 위치와 상태를 확인하고 작업 파일을 덮어쓰지 않습니다.
3. **SKILL.md의 최초 준비 절차를 실행합니다.** Python 버전과 의존성을 확인하고 전용 가상환경을 준비합니다. 사용자에게 명령 목록을 떠넘기지 말고 가능한 작업을 직접 수행합니다. 직접 설치할 수 없는 항목만 사용자에게 다음 행동을 안내합니다.
4. **설치 상태를 구분해 확인합니다.** 가상환경에서 조회 스크립트의 `--help`가 실행되고 엑셀 생성 모듈을 불러올 수 있는지 확인합니다. 캡처를 선택했을 때만 브라우저를 확인합니다. 이것은 설치 점검이며 실제 사이트 조회 성공과는 다릅니다. 호스트의 자동 스킬 등록은 별도 기능이므로 실제 등록을 확인한 경우에만 등록됐다고 안내합니다.
5. **첫 조회에 필요한 정보를 받습니다.** SKILL.md의 입력 파싱 절차에 따라 토지 목록·회사명·감사기준일을 확인합니다. 감사기준일을 전달받았다는 이유만으로 조회 가격이 그 날짜에 맞춰 필터링된다고 설명하지 않습니다.
6. **결과를 확인하고 인계합니다.** 실제 조회 후 JSON·엑셀과 요청된 선택 결과가 생성됐는지 확인하고, 사용자가 열 수 있는 위치와 성공·실패 항목을 알려줍니다. 이미지는 선택 기능이며 조서에도 첨부 여부가 표시됩니다. 요청된 캡처가 실패한 경우 이를 명시합니다. 재시도 방법은 SKILL.md의 오류 처리를 따릅니다.

## 무엇을 하나
- 필지(주소 + 지번) → realtyprice 개별공시지가 조회 (연도별 전체, 무인증 내부 API)
- 선택적으로 실제 조회 화면을 **그대로 스크린샷**(재현물 아님 — 감사 증빙용)
- 요약 시트 + 물건별 시트의 **엑셀 워크페이퍼** 생성, 이미지 삽입 선택
- **다수 필지 일괄 조회** (한 건 실패가 전체를 막지 않음)

## 설치 (AI가 대신 실행)
아래 명령은 에이전트가 실행할 참고 절차입니다. 공시지가 조회용 API 키나 계정은 필요하지 않습니다. Python ≥ 3.10을 사용합니다.

```bash
cd <skill-dir>
python scripts/setup_venv.py            # 스킬-로컬 .venv + openpyxl (조회·엑셀)
```
기본 설치에는 Pillow·Playwright·브라우저가 없습니다. 이미지 삽입은 `--with-images`, 자동 캡처는
`--with-capture`를 선택할 수 있습니다. 설치 구성·기존 환경 전환·headless 브라우저 안내는
[SKILL.md의 최초 준비](./SKILL.md#실행-환경--최초-준비-스킬-구동-llm-용)를 따릅니다.
> `setup_venv.py` 로 `.venv` 를 만들면 이후 실행은 그 venv 파이썬으로 한다
> (Windows `.venv\Scripts\python.exe …`). 자세한 준비 절차는 `SKILL.md` 의 "실행 환경 & 최초 준비".

## 사용법
### Claude 에게 (권장 — 자연어)
> "서울 중구 충무로1가 24-2 공시지가 조회해서 워크페이퍼로 정리해줘"

SKILL.md 절차에 따라 조회 → 엑셀 생성을 수행한다. 화면 증빙을 요청하면 실제 스크린샷도 생성한다. 여러 필지를 한 번에도 가능.

### CLI
```bash
# 조회 데이터
python scripts/query_api.py --sido 서울특별시 --sigungu 중구 --dong 충무로1가 --bun1 24 --bun2 2
# 실제 웹페이지 스크린샷 (--with-capture 설치 후)
python scripts/render_screenshots.py --sido 서울특별시 --sigungu 중구 --dong 충무로1가 \
    --bun1 24 --bun2 2 --out <보관소>/output/01_충무로1가_24-2.png
```
`<보관소>` 는 `CPA_SKILLS_STORAGE`(없으면 `~/cpa-skills-data`) 아래 `skill-land-price-query` 폴더다.
출력 경로를 생략하면 `<보관소>/output` 에 쓰고, git 저장소 안 경로는 거부한다.

## 아키텍처
- **조회 데이터**: 표준 라이브러리 `urllib` 로 realtyprice.kr 내부 API 직접 호출(빠름, 무인증)
- **스크린샷**: `Playwright`(headless Chromium)로 실제 웹페이지 조작·캡처
- **엑셀**: `openpyxl` (+ `pillow` 로 임베드 이미지 비율 계산)
