# 공시지가 조회

## 절대 어기지 않는 것

1. 공개는 허브(cpa-skills)의 공개 명령으로만 한다. 스킬 저장소와 허브는 언제나 private 이며 public 으로 바꾸지 않는다.
2. 고객 자료·자격증명을 커밋하지 않는다. 실제 재무제표, 감사조서, 실명 회사 정보, `.env`, 키 파일. private 저장소도 안전 보관이 아니다.
3. 회사·거래처·계정과목이 바뀌면 깨지는 규칙을 코드에 넣지 않는다. 그런 규칙은 문서에 둔다.
4. 확인하지 않은 것을 확인한 것처럼 집계하지 않는다. 계산 실패·미계산·보류를 정상으로 세지 않고, 산출물에 '통과'라고 쓰지 않는다.
5. 실자료와 산출물은 저장소 밖 보관소 `<루트>/<스킬 폴더명>/{input,work,output,logs}` 에만 둔다. 자리는 실행 옵션 > 환경변수 `CPA_SKILLS_STORAGE`(루트) > `~/cpa-skills-data` 순서로 정하고, 경로 해석은 허브 틀 `cpa_storage.py` 의 사본으로 한다. 코드에 이 PC 전용 경로를 넣지 않고, git 저장소 안에는 쓰지 않는다.

공통 규범 전문은 허브 저장소(cpa-skills)의 `docs/` 에 있다. 이 저장소에서는 허브 문서를 고치지 않는다.

## 이 스킬이 맡는 것

부동산공시가격알리미에서 개별공시지가를 조회하고, 감사 워크페이퍼(엑셀)를 만들며,
필요하면 실제 조회 화면 스크린샷을 첨부한다.

- `scripts/` — 입력 파싱, 조회 호출, 스크린샷 캡처, 엑셀 생성.
- `scripts/cpa_storage.py` — 보관소 경로 해석. 허브 틀 사본이라 고치지 않는다(허브 `check` 가 대조).
- 의존성이 셋으로 나뉜다 — 기본(`requirements`), 캡처용(`requirements-capture`),
  이미지 처리용(`requirements-images`). 스크린샷을 쓰지 않으면 기본만 설치하면 된다.

## 맡지 않는 것

- **토지 평가나 손상 판단.** 공시지가를 조회해 옮길 뿐, 그 값으로 회계적 결론을
  내리지 않는다.
- 등기부 정보. 소유자·담보는 등기부 분석 스킬의 몫이다.
- 주소 정규화 서비스. 입력 주소가 조회되지 않으면 그대로 실패로 남긴다.

## 반드시 지켜지는 것

- **조회 실패를 값 0이나 공란으로 대체하지 않는다.** 조회되지 않은 필지는 조서에
  조회 실패로 남는다. 감사 조서에서 빈칸과 0은 다른 뜻이다.
- **스크린샷은 선택이다.** 캡처 의존성이 없어도 조회와 엑셀 생성은 끝까지 돌아야 한다.
  캡처 실패가 전체를 중단시키지 않는다.
- **기준 연도를 결과에 명시한다.** 공시지가는 연도별로 다르므로 어느 시점 값인지
  없으면 조서로 쓸 수 없다.
- 외부 사이트 응답 구조가 바뀌면 조용히 잘못된 값을 넣지 말고 실패로 남긴다.

## 의존과 환경

| 필요한 것 | 없으면 |
|---|---|
| 브라우저 자동화 의존성(`requirements-capture`·`requirements-images`) | **스크린샷 단계만 건너뛴다.** 조회와 엑셀 생성은 끝까지 돈다 |
| realtyprice.kr | 이 스킬만 동작하지 않는다 |

## 테스트

```bash
uv run --no-project --with-requirements requirements.lock --with-requirements requirements-images.lock --with pytest python -m pytest tests -q -p no:cacheprovider
```

현재 **22건 통과** (2026-09-25 실측). 테스트는 `tests/conftest.py` 가 `CPA_SKILLS_STORAGE` 를 임시 폴더로 돌려 실제 보관소에 쓰지 않는다.

무엇을 테스트해야 하는가: 외부 사이트를 실제로 부르는 경로는 테스트에서 분리한다.
파싱 로직은 저장된 응답 샘플로 검증하고, 응답 구조가 예상과 다를 때 실패로 떨어지는지
확인한다. 조회 실패가 0으로 바뀌지 않는지를 반드시 포함한다.

## 공개 상태

공개 여부는 허브(cpa-skills)의 `config/publishing.yml` 이 정한다 — 이 저장소에는 적지 않는다. 공개되면 이 폴더의 파일이 공개 미러를 거쳐 사이트에 나가므로, 늘 아래를 지킨다.

- 문서와 코드에 운영자 절대경로·호스트 이름·단축 커맨드 표기를 쓰지 않는다.
- 예시에 고객이나 실제 소유자와 이어지는 이름·주소를 넣지 않는다. 널리 알려진 공시 필지(예: 서울특별시 중구 충무로1가 24-2, 전국 최고 공시지가 부지)는 공개 정보라 조회 예시로 쓴다.
- `requirements.txt` 를 유지한다. 의존성이 셋으로 나뉘므로 **세 개 모두** 느슨한
  사본이 있어야 한다 — `.lock` 과 `.in` 은 공개되지 않는다.
- 공개 주소는 **폴더명**(`skill-land-price-query`)을 그대로 쓴다. 폴더명을 바꾸면 이미 공개된
  링크가 깨진다. frontmatter 의 `name`(`land-price-query`)과는 다른 값이다.
